# RouterArena Leaderboard Submission — llm-router

Submission packet for [RouteWorks/RouterArena](https://github.com/RouteWorks/RouterArena).
Generated by llm-router's `routerarena_tuned` policy (Plan 06 Steps 1+2)
layered on the Plan 07 routing infrastructure (subject classifier, bandit
telemetry, calibration, provider-quirk registry).

## Files

| File | Purpose | Generated by |
|---|---|---|
| `config.llm-router.json` | Router config — model list + description | hand-written |
| `llm-router-sub_10.json` | sub_10 predictions with `generated_result` | `scripts/routerarena/build_submission.py --split sub_10` |
| `llm-router.json` | Full split predictions (when generated) | `scripts/routerarena/build_submission.py --split full` |
| `llm-router-robustness.json` | Robustness predictions (routing-only) | `scripts/routerarena/build_robustness.py` |

## Reproducing this submission

```bash
# Prerequisite: OpenRouter API key + parquet files at ~/.llm-router/data/routerarena/
export OPENROUTER_API_KEY=sk-or-v1-...
mkdir -p ~/.llm-router/data/routerarena
curl -L -o ~/.llm-router/data/routerarena/sub_10.parquet \
  "https://huggingface.co/datasets/RouteWorks/RouterArena/resolve/main/data/sub_10-00000-of-00001.parquet"
curl -L -o ~/.llm-router/data/routerarena/full.parquet \
  "https://huggingface.co/datasets/RouteWorks/RouterArena/resolve/main/data/full-00000-of-00001.parquet"
curl -L -o ~/.llm-router/data/routerarena/robustness.parquet \
  "https://huggingface.co/datasets/RouteWorks/RouterArena/resolve/main/data/robustness-00000-of-00001.parquet"

# Build sub_10 predictions (~$0.50, 30-40 min)
uv run --with pandas --with pyarrow python scripts/routerarena/build_submission.py \
  --split sub_10 --out submissions/routerarena/llm-router-sub_10.json

# Build full split predictions (~$3-5, 4-5 hours)
uv run --with pandas --with pyarrow python scripts/routerarena/build_submission.py \
  --split full --out submissions/routerarena/llm-router.json

# Build robustness predictions (no inference — routing only, runs in seconds)
uv run --with pandas --with pyarrow python scripts/routerarena/build_robustness.py \
  --out submissions/routerarena/llm-router-robustness.json
```

## Routing strategy (per `policies/routerarena_tuned.yaml`)

| Subject (Plan 07 Cat B classifier) | Specialist routed to (OpenRouter) |
|---|---|
| code | `qwen/qwen3-coder-next` |
| medical, history | `google/gemini-3.1-flash-lite` |
| reasoning | `x-ai/grok-4.3` |
| physics, narrative | `deepseek/deepseek-v4-flash` |
| general (no specialist) | workhorse: `qwen/qwen3-235b-a22b-2507` |

Free-first chain (Ollama → OpenRouter) is preserved by the policy, but the
submission run intentionally skips Ollama (local install + Codex
subscription aren't reproducible by the RouterArena evaluator) so every
prediction lands on an OpenRouter model the evaluator can re-run.

## Opening the leaderboard PR

Per the RouterArena README:

1. Fork `RouteWorks/RouterArena`.
2. Copy these files into the fork:
   ```
   router_inference/config/llm-router.json
       (this packet's config.llm-router.json — note RA expects llm-router.json filename)
   router_inference/predictions/llm-router.json
       (this packet's llm-router.json — full split)
   router_inference/predictions/llm-router-robustness.json
       (this packet's llm-router-robustness.json)
   ```
3. Open a Pull Request to `main`.
4. Comment `/evaluate` in the PR.
5. Wait for the automated workflow to run inference + score + post results.
6. Leaderboard updates on PR approval.
