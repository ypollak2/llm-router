This is what every file actually does when run today, which is not what the
original README assumed for several of them.

## The finding that matters

**`test_hook_equivalence.py` has been silently SKIPPING, not failing.**

Its `_HOOK_PATH` uses `parents[2]`, which resolved correctly from `tests/` and
points ABOVE the repository from `_quarantined_tests/`. The hook therefore fails
to load, the module calls `pytest.skip`, and all 25 cases report as skipped. A
file reporting "25 skipped" reads like a deferred decision. It is not: run it from
`tests/` with the path corrected and all 25 FAIL, on `classify.INTENT_WEIGHT` —
privatised by the sync.

That matters beyond this directory. This is the test that asserted the hook's
classifier stays equivalent to `llm_router.classify`, and the hook and the router
now disagree on complexity for 40% of prompts (A4 in
`docs/archive/ACTIONS_REMEDIATION_RUN.md`). The check that would have caught the
divergence was present the whole time and could not run.

## What was NOT done

Eleven files still need the work the original README asks for: diffing their
assertions against the upstream tests that supposedly replaced them. "Upstream has
a file with a similar name" is not the same claim as "upstream asserts the same
behaviour", and only the second justifies dropping coverage. Deleting them without
that diff would be exactly the silent coverage loss the quarantine exists to
prevent.

The two deletions above were made because a live, passing test with the same
subject was verified to exist — not because a similarly-named file was spotted.
