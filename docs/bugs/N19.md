## N19. A model that cannot serve generate/chat entered llm(task=code) chains and failed on every call

- **Symptom (2026-10-10, M0-3 rerun `chain_attempts`).** `ollama/nimble:9b` (a decision classifier) was attempt A5 in
  a code chain and returned 400 "does not support generate" in ~30 ms, every call.
- **Cause.** `config.all_ollama_models()` takes every model in the discovery cache and `discover._is_embedding_model`
  drops only names/families that look like embedders. Nimble matches neither.
- **Fix.** `discover.ollama_can_generate()` asks Ollama (`POST /api/show`, `capabilities`) and drops a model whose list
  lacks `completion`. It is applied in `get_cached_ollama_models` (the source of `all_ollama_models`, including a
  stale cache) and `_probe_ollama_direct`. A definite answer is cached per process. It fails open: no base URL,
  unreachable `/api/show`, an Ollama that returns no `capabilities`, or any error keeps the model (a failed lookup is
  not cached). The classifier names its model itself (`decision_classifier.DEFAULT_MODEL`) and never reads this list,
  so it still works. The explicit `OLLAMA_BUDGET_MODELS` fallback is untouched.
- **Tests.** `tests/test_local_model_hygiene.py::test_n19_*` (stubbed Ollama HTTP). All fail on main.
- **Residual.** A model whose `capabilities` omit `completion` but that serves chat is dropped; none known.
- **Also excluded by name:** `llmr-classifier` (a qwen3.5 Modelfile, so `/api/show` reports `completion`) served an
  `llm(task="code")` call in M0-3 rerun2 (B6). `discover._CLASSIFIER_ONLY_BASES` drops it from chains; the classifier
  names it explicitly.
- **Cache.** Definite verdict 1 h; unknown (Ollama down, /api/show error or 404) fail-open for 60 s so routes do not
  pay the 2 s timeout per model. The `OLLAMA_BUDGET_MODELS` fallback is filtered too.
- **Coordination.** Draft #402 (P1.8) adds `local_models.ROLES` (nimble = decision). Whichever PR lands second must make
  chain building consult ROLES as the single source of truth and fold `_CLASSIFIER_ONLY_BASES` into it.
