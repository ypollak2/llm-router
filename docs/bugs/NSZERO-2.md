## NSZERO-2. The Stop line and `llm-router northstar` still printed a per-session strict share that could only be zero, after NS went blind everywhere else

- **Symptom (2026-11-03).** With NS blind on the status line and in `llm-router kpi` (NSZERO-1), the Stop line still printed `north star (strict) 0% (n=1795)` and `llm-router northstar --days 7` printed `verified offload 0.0%  (n=1795)` and `median=0.0%  p25=0.0%  max=0.0%` for the same organic session (1 session, n=1,795 main-file units, 7 d, a copy of `~/.llm-router` and its organic transcripts on main 16fc9296, `src/llm_router/northstar.py`).
- **Cause.** Both read `northstar.report()`. Its per-session `strict_share` is `strict_used` over units, and `strict_used` counts units that pass `is_strict_used`, which needs a `verify` record that `report()`'s unit stream never carried (the same source as NSZERO-1). The share could not be anything but 0, and the Stop line and the CLI printed it as a measurement.
- **Fix.** `report()` counts verdicts per session (`northstar.has_verdict`) and marks a session with none `strict_blind: true` with `strict_share: null`; the `strict_*` aggregate leaves blind sessions out and `aggregate.strict_blind` says so; it asks `units()` through the seam `NS_ATTACH_VERIFY_RECORDS`. `current_session_line` returns `north star (strict): blind (no verifier connected)` with no n: the Stop path counts main-file units only, so an n there would not be the status line's n, and it never reads a sub-agent transcript (`report()` takes `subagents=False` by default and a test spies on every file it opens). `llm-router northstar` (`src/llm_router/commands/northstar.py`, not a hot path) passes `subagents=True`, so its n is the n of `kpi`, and prints `verified offload blind (no verifier connected)  (n=7344 units, 7d)`, its aggregate the same way, and a measured row with its unit and window too; a single-session run reads only that session's sub-agent files. `--json` carries `strict_blind` and a null `strict_share`.
- **Test.** `tests/test_w8_ns_surfaces.py` (14 cases: the report for a blind, a measured, a mixed and a too-few population; the seam and the no-sub-agent spies; the Stop line's states; the Stop child caching the blind line and the next Stop showing it, full and condensed; the CLI blind, measured, JSON, sub-agent counting and single-session reads). Against the commit before this fix 13 of the 14 fail; `tests/test_northstar.py::test_report_schema_is_pinned` pins the new keys.
