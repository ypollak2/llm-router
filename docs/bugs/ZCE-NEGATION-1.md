## ZCE-NEGATION-1. "Do not modify anything yet" turns were classified as edits and taken over by zero-Claude edit

- **Symptom (2026-11-11).** `zero_claude_edit.classify_edit_prompt` returned `is_edit=True` (2 files, reason `edit verb + 2 named file(s)`) for 16 of 16 synthetic LONG-Q S-tier first turns (`~/.rsi/research/primary-plan/v16/synth-live/longq/prompts.lq1.json`, tier S, turn 1, n=16 of 54 sessions). Each turn opens "Do not modify anything yet. First run `grep -n ...`" and asks what a function returns: a read/investigate request. On a failed local edit the hook blocks the prompt (by design), so these turns would be blocked for an edit nobody asked for. M, L and L2 first turns (n=38) were rejected as "too broad" only because they name 5, 12 and 18 files.
- **Cause.** `_EDIT_VERB_RE` matched the negated "modify" (and "append" in the pasted source), and the 2 `### file:` headers satisfied the 1-3 file rule. Nothing read the negation.
- **Fix.** `_NEGATED_EDIT_RE` in `src/llm_router/zero_claude_edit.py`, checked in `classify_edit_prompt` before the verb match, matches only a temporal or preparatory negation: "do not / don't / never <edit verb> anything yet|for now|until" and "before (you) changing/modifying/editing/touching/writing anything". Scope limiters ("don't modify anything except a.py", "never touch any file outside src", "don't change any code in c.py", "don't change anything else") do not match and stay edits. A first review (cdb520e0) found the first version, which also matched "anything|any file|any code", suppressed those genuine edits; it was narrowed.
- **Known limit.** The negation is searched over the whole prompt, so a mixed prompt ("Don't modify anything yet. First read a.py. Then rename foo to bar in a.py and b.py.") is not an edit. A false negative falls through to Claude, the safe direction.
- **Test.** `tests/test_zero_claude_edit_scope.py::test_classify_negated_edit_is_not_an_edit` (3 cases) and `::test_classify_two_file_edit_still_an_edit` (6 cases, 4 of them the scope limiters above). Run alone: the negated cases fail 3 of 3 on origin/main and pass on the fix; the 6 edit cases pass on origin/main and on the fix and are regression guards; against the first version (cdb520e0) 4 of the 6 fail.
