## BIND-7. A repository's own `core.worktree` could widen a delegated run's writable root to an ancestor directory

- **Symptom (2026-11-03).** Reproduced end to end through the real hook by the independent review of PR #818 (n=1 case): repository `proj/a` with `core.worktree=proj` in its own `.git/config`, session in `proj/a/sub`. `git rev-parse --show-toplevel` answers `proj`, the hook launched `-C proj --sandbox workspace-write`, and the sibling repository `proj/b` was inside the writable root. It needs write access to the repository's `.git/config`, so the likelihood is low, but the root of a sandbox is the one value that must not be settable by what runs inside it.
- **Cause.** `_git_toplevel` accepted any answer that contains the session directory, which was the first push's fix for a `core.worktree` that points somewhere unrelated (tests/test_bind_agent_route_handoff.py::test_a_repository_cannot_move_the_writable_root_with_core_worktree). An ancestor contains the session directory too.
- **Fix.** The top level must also be the NEAREST directory at or above the session's that carries a `.git` entry: a directory, or the file of a linked worktree or a submodule. That is the repository the session is really in; the entry is looked for with `lexists`, so a gitfile or a symlink counts. When the ancestor is itself a repository the nearer `.git` still wins. Anything else is "no repository", and the run is read-only.
- **Test.** `tests/test_bind_agent_route_handoff.py::test_a_repository_cannot_widen_the_writable_root_to_an_ancestor_with_core_worktree` (2 cases: the ancestor has no `.git`, the ancestor is a repository; each first asserts that git really answers the ancestor) and `::test_a_linked_worktree_and_a_submodule_style_gitfile_still_count_as_a_repository` (the check must not turn a gitfile into "no repository"). Two narrow mutations, each turning a named test red: the nearest-entry comparison dropped (2 cases), `lexists` replaced by `isdir` (1). Rule: a sandbox root is derived from what the session's own directory proves, never from a value the repository's config can set.
