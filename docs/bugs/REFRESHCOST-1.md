## REFRESHCOST-1. Counting sub-agent calls made every status-line refresh decode every sub-agent transcript

- **Symptom (2026-11-03).** The independent review of PR #821 measured the refresher (`llm-router statusline --refresh`, which builds `statusline_cache.json`) at 8.5 s per run on main and 12.1 s on the PR, +43% (`~/.rsi/research/primary-plan/v16/coord/rv-PR821-20261103.md`, 5 runs, 278 sub-agent files). Re-measured on a copy of 8 days of this machine's data (5 interleaved runs of `statusline_refresh.build()`, 2026-11-03): median wall 11.2 s on main 16fc9296 and 13.3 s on 34b9985c, CPU 9.7 s and 11.6 s. The refresher starts at most once per 60 s (`statusline_tick.REFRESH_AFTER_S`) while the status line is drawn, so the extra 1.9 s of CPU was a standing cost, not a one-off.
- **Cause.** The sub-agent scan (NSSUB-1) decoded every record of every sub-agent file each time, although a file that has not changed gives the same units; json decoding of 278 files was the added time.
- **Fix.** `northstar.build_sessions(subagents=True)` keeps `[id, model, ts]` per message for each sub-agent file in `northstar_subagent_index.json`, keyed by the file's `(size, mtime_ns)`; an unchanged file yields its units from the index. A file with an MCP call (its units take a model from the routing table and a verdict from the records) or with a message a proxy served is always read in full. A damaged, foreign-version or malformed index is ignored and rebuilt; entries of deleted files are dropped. Steady state on the same copy (n=4 warm runs, PR #821 body): median wall 9.6 s and CPU 8.9 s, under main's 11.2 s and 9.7 s.
- **Test.** `tests/test_w8_subagent_index.py` (17 cases: a second scan decodes 0 unchanged files; an appended or touched file is decoded alone; cold, warm and rebuilt scans give equal units; the MCP and proxy-served exceptions; damaged, foreign and malformed indexes; the hot-path default never reads or writes it; single-session, deleted-file, window and 0600 cases). Disabling the index hit path fails 5 of them, ignoring the file state fails 2, trusting an MCP-bearing file fails 1.
