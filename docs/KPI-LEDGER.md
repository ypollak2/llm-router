# KPI Ledger

One row per change, per the change rule in
[`repo_goals/KPIS.md`](repo_goals/KPIS.md). Every PR names its primary KPI, what it
expected to move and by how much, and the guardrails it touches; this table records
what was actually measured, offline and/or live, with the n and window.

"Not measured" means exactly that — no number exists for that cell, not zero. A verdict
of **not measurable yet** means the change shipped before the measurement it needs
exists (see the Gaps section of `repo_goals/KPIS.md`); it is not a judgment that the
change was wrong.

Rows #240–#248 below are a backfill: these PRs merged before the KPI set was adopted on
2026-10-03, so none of them named a primary KPI or an expected size at open time. Each
row assigns the KPI the change actually bears on, in hindsight, and quotes only numbers
that appear in the PR's own body.
