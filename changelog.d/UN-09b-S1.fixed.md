UN-09b S1: in Claude subscription mode, a request that names a Claude model is no longer served by Claude through the two paths that still could. The emergency budget fallback chain (walked when the named request's other providers fail) and a routing-policy subject specialist now drop every `anthropic/*` model for that request, as the main chain already did. When nothing else is left, the request ends in the router's existing refusal ("... is not served in subscription mode ..."), followed by the list of failed attempts, instead of a Claude answer. Un-named requests, named non-Claude models and non-subscription mode are unchanged. Evidence: `tests/test_un09b_blocked_named_model.py`.
