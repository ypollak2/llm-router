UN-09b S1: in Claude subscription mode, a request that names a Claude model is no longer served by Claude through the three paths that still could. The emergency budget fallback chain (walked when the named request's other providers fail) and a routing-policy subject specialist now drop every `anthropic/*` model for that request, as the main chain already did, and the semantic cache is not consulted for it (a stored answer may be Claude's). When the emergency chain held nothing but Claude, the request ends in the router's existing refusal ("... is not served in subscription mode ..."). When its other entries fail, it ends in the same "All models failed" error as before, with one added sentence saying `anthropic/*` was not tried; the HTTP status, the ledger reason, and the rule that provider error text never reaches the client are unchanged. The same wiring applies to a named `gemini/*` model in Gemini subscription mode, where it is redundant in practice because that mode already removes Gemini from the available providers. Un-named requests, named non-Claude models and non-subscription mode are unchanged. Evidence: `tests/test_un09b_blocked_named_model.py`.
