Proxy ledger: new `prev_tool_targets` field, a list of `{name, h}` per previous tool call, where `h` is a 12-hex HMAC-SHA256 of the normalised file path (Edit/Write/MultiEdit/NotebookEdit/Read) or Bash command, keyed by a per-install 32-byte salt in `<router home>/prev_target_salt` (mode 0600). It lets an offline D3 redo check see that the same file or command was targeted again; no raw path or command is stored.
