CTX-PROJ-1: one session id now keeps one session-context file. The project hash comes from the session's cwd record (`session_cwd_<sid>.json`), pinned atomically on first use in `session_project_<sid>.json`, instead of the writing process's cwd, so Bash-spawned test/E2E processes and `cd` into a worktree no longer scatter a session's events across several `projects/<hash>/` shards. Precedence: `LLM_ROUTER_PROJECT_ID`, then the session's pin (it outranks a caller-supplied `project_root`, which for MCP/gateway callers is the session's latest cwd), then the caller's `project_root`, then the writer's cwd. When a pin is first created, the session's earlier shards (live and archived) in other project dirs are merged into the pinned project, so a session running across the upgrade keeps its history. `cleanup_old_sessions` now also removes aged `session_project_<sid>.json` / `session_cwd_<sid>.json` files whose session has no log left.
