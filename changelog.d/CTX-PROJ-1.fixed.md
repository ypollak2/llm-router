CTX-PROJ-1: one session id now keeps one session-context file. The project hash comes from the session's cwd record (`session_cwd_<sid>.json`, pinned on first use in `session_project_<sid>.json`) instead of the writing process's cwd, so Bash-spawned test/E2E processes and `cd` into a worktree no longer scatter a session's events across several `projects/<hash>/` shards. `LLM_ROUTER_PROJECT_ID` and an explicit `project_root` still win; with no session id or no cwd record the old behaviour applies (events written before the first hook record stay in the writer-cwd shard).
