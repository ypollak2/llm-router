The status line's savings figure now counts every routing that saved money (owner decision D-611), not only human turns whose first call left Claude: hook/MCP/agent-door savings (usage.db), proxy locally served runs (`_net_avoided`, once per served run, never a sum of per-step counterfactuals) and proxy tier rewrites, deduplicated by `trace_id`. The router line shows `saved ~$X est. (n=…: hook/MCP · local steps/runs · tier, today) · ~$Y est. 30d`; a window whose net is at or below zero shows `saved n/a (net <= 0: local -$X, other +$Y, <window>)`, never `~$0` (D-613); the work-hours figure is appended only when measured. New `llm-router savings` prints per-source history for today, 7 d, 30 d and since each source's first row, with counts and excluded rows (D-614). History comes from a background rollup (`savings_rollup.json`) built by one resumable forward pass that buckets every ledger row by its own day, because the proxy ledger is not written in time order; the render path reads only the cached line. Late served rows for days older than 3 days are priced as their own run (about one run's net per such row; counted and footnoted). Estimates, not realized money.
