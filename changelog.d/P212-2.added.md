P2.12 (P212-2): the npm postinstall now wires your hosts. After it downloads the binary and checks that it runs, it runs `llm-router install --auto` and echoes that run's `receipt:` line, replacing the old "next step -> llm-router install" hint; the Claude Code plugin pointer is now printed only when no host was wired, since the plugin after a successful wiring would register the same hooks twice. If the installer fails or cannot start, the postinstall prints a warning with the installer's reason and the `llm-router install` command to retry, and still exits 0, so `npm install` keeps the working binary; the failure stays in the install receipt. A failure to download or run the binary is still fatal. Set `LLM_ROUTER_NO_AUTO_INSTALL=1` to install the binary without wiring any host (an install-time switch, not a documented setting). Evidence: `tests/test_npm_wrapper.py` (P212-2 section; real node against a stub binary in a fixture HOME, including the full `node install.js` run with the release download served from a local tarball; fails rather than skips in CI when node is missing).
