Proxy: `proxy/cls_embed.py`, an embedding classifier backend, off by default (`LLM_ROUTER_CLS_EMBED=shadow` turns it on) and not called by any routing decision yet. It embeds on the small Ollama server only (loopback, never the main model's server, never port 11435), with a 250 ms budget (`LLM_ROUTER_CLS_EMBED_BUDGET_MS`), `keep_alive`, a start-up warm-up, a 5-error / 60 s breaker, an in-flight depth of 4, and a kill file `cls_embed.off` in the state directory. It scores against a hash-checked head artifact; with no artifact, a bad hash or a dimension mismatch it abstains (a bad artifact also records `LR-FO-CLS-EMBED-ARTIFACT`). Its verdict fields (`cls_emb_*`) hold numbers and codes only, never text.
