F111 (follow-ups to P35-3): the Codex Stop hook (`codex-stop.py`, hook version 2 -> 3) and the Pi summary extension now find the state home the way llm-router does: `LLM_ROUTER_HOME` from the real environment, else from `~/.llm-router/.env`, else from `~/.env`. A user who set it only in the default-home `.env` no longer gets a permanent `n/a` while the refresher wrote to the configured home. Both read that one key by hand (no `llm_router` import: latency). The refresh rate limit is now per session (one small stamp file per session in `.codex-stop-refresh.d/` / `.pi-summary-refresh.d/`, stamps older than 1 h removed, at most 64 kept), so a second session within 10 s is no longer starved. The old single stamp file is left unused. `codex-stop` now writes its own G1 row to `hook_latency.jsonl` (hook, event, elapsed_ms, timed_out, ts, session_id, host, load1; same shape as `hook_latency.record`; skipped when `LLM_ROUTER_HOOK_LATENCY` is off or the log is over its cap, which the rotating writers handle). Install the new copy with the usual hook redeploy.
