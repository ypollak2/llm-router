- Proxy: embedding-classifier AUTHORITY for agent turns (`proxy/cls_embed_authority.py`, PR-7), a capability that is OFF by default: it runs only with `LLM_ROUTER_CLS_EMBED_AUTHORITY=decide` AND the embed backend on (`LLM_ROUTER_CLS_EMBED=shadow`) AND no `cls_embed_authority.off` file in the state dir (checked on every call). With it off, decisions, ledger rows and goldens are unchanged. On, a decided `local` verdict from the embed head may turn ONE rules refusal into `local`: a plain conversation pin to Claude (not a structural pin, not a hard pin, not `started_elsewhere`). The whole rule set is re-run with the pin waived, so the kill switch, `claude_marker`, exempt sessions, hard pins, media, the prompt cap, backend health, the breaker and a classifier veto still refuse, and the cap guard and the cold guard still run after the flip; permission checks / `not_eligible` side calls are never classified and never local (D-594). A `claude` verdict, an abstain, a timeout, a missing artifact or a full queue leave the rules' decision. The verdict runs on its own 4-thread executor inside `asyncio.wait_for` at the embed budget (250 ms default). With the flag on, rows get `cls_opened` (true when the classifier opened the call, text-free) and `cls_opened_by`, plus the `cls_emb_*` numbers. Folds the PR #957 follow-ups: the shadow record keeps `rules_decision` (pre-flip) and adds `final_decision` and `flipped`; the embed read has a total deadline (a trickling server can no longer hold a pool thread past the budget); the shadow lane builds no new lane after shutdown and skips turns with no `text_sha`; an end-to-end test shows a unique user string never reaches `cls_embed_shadow.jsonl` or the ledger.
