Claude Code sub-agent rows (`provider 'cc'`, hook `cc-usage-track.py`, hook version 9) now record the model the sub-agent ran on, at its `llm_router.pricing` price. The old table guessed the model from `subagent_type` (Explore and general-purpose as `claude-haiku-4-5-20251001`, the rest as `claude-sonnet-4-6`), but Claude Code takes the model from the Agent call's `model`, then the agent definition's `model:` frontmatter, then the parent session. The hook now tries, in order: `tool_response.resolvedModel` / `model`, `tool_input.model` (an explicit `inherit` goes to the parent), the definition's `model:` (`<cwd>/.claude/agents/`, then `~/.claude/agents/`; no `model:` or `inherit` goes to the parent), and the parent transcript's latest real main-chain assistant model (sidechain and `<synthetic>` records skipped). A present but unrecognised value ends the search as unknown. Claude Code aliases map to `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5` and `claude-fable-5-2` through `pricing.claude_code_model`. The `tool_response.resolvedModel` source is assumed, not observed: it is proven only in transcript `toolUseResult` records (3,132 of 3,132 in a local scan, 2026-11-23), and no recorded PostToolUse Agent payload carries it, so the hook falls through when it is absent. File reads are bounded (definition 8 KiB, transcript tail 256 KiB), regular files only, and a definition must resolve inside its agents directory.
When no step names a model, or the model has no price (`claude-fable-5-2` today), the hook writes an explicit unknown row instead of dropping the call: model `unknown` (or the unpriced id), 0 tokens, NULL `potential_cost_usd` and `saved_usd`, reason `claude_code_subscription:unknown_model:<why>`. It stays in the call count and in the subscription class, and no money reader counts it as a saving. Before this change such a sub-agent was recorded as Sonnet. Rows already in the ledger (3,134 on 2026-11-22: 1,622 `claude-haiku-4-5-20251001`, 1,512 `claude-sonnet-4-6`) keep their old model and price; nothing is backfilled.
