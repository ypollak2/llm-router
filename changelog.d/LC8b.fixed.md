LC-8b (hardening of the local-check routing, rv-675): settings parity replaces ctx hash equality (a lane records the `ctx` and `think` it was measured with; it is preferred when route-time thinking is off, the router's ctx is >= the measured ctx and the input fits `min(scope.max_prompt_chars, router window)`; temperature is not part of the claim; a lane recorded before this keeps the hash rule), and a passed lane that is withheld records a `not_preferred` skip cause and a `doctor` line instead of staying silent. Routing now needs a verified digest match from the inventory cache (the 30-day no-digest rule is display only), and an entry enabled from `local_check` no longer falls back to a pre-registered lane when its own lane goes stale. The demotion monitor counts per-attempt LOCAL outcomes (`text_job_local_attempts.jsonl`), so a dead or slow Ollama rescued by the next chain entry demotes at 7 of 20. `enable`/`disable`/`on_pass` are one locked read-modify-write with unique temp files; an untagged name is stored as `<name>:latest`. The `local-check enable|disable` CLI comes with LC-6, not LC-8. Evidence: `tests/test_lc8b_hardening.py`; see `docs/local-check-routing.md`.
