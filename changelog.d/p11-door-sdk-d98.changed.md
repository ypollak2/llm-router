PLAN v16 P1.1 door 6 rework (D-98): `llm_router.route(messages=...)` no longer goes through `route_and_call`. The history now feeds `build_pack(door="sdk")` inside the SDK's own `build_chain` + `execute_chain` (or agent-loop) call, so model choice, the local agent loop for file tasks, `timeout` and the `host="sdk"` ledger rows are the same with and without `messages`. The pack is sent as the executor's `history` (text chain) or folded into the agent loop's context, and only when `session_store.allows_session_content` allows the most external provider in the chain, because a fallback model receives the same context (privacy mode `local` = on-device providers only, D-91/D-95). Leading assistant turns are dropped; a pack failure records `CHZ-FO-SDK-PACK` and sends the request alone. `route_and_call`'s `context_door` default is now `"gateway"`, the only door that still uses it (D-43(c)); the router-level `messages=` tests moved to `tests/test_route_and_call_messages.py`.
