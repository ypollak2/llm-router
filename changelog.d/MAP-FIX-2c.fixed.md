MAP-FIX-2c: `refresh_seats` (used by `llm-router doctor`, `llm-router install` and the session-start hook when its seat cache is over 24 hours old) now applies the same carry rule as the discovery rescan. A "CLI not found" or failed-probe verdict from a process that cannot see the CLI no longer overwrites a claude, codex or gemini seat that another writer saw connected within the last hour; the carried save keeps the sighting's `detected_at`, so the carry still ends an hour after that sighting and a real uninstall is then written. Learning CLI dirs into `cli_path.json` now tells a busy lock from a filesystem without locking: a busy lock still skips the write, and when locking is unavailable (for example `ENOLCK` on an NFS home) the entry is written unlocked, as before MAP-FIX-2b, and counted as fail-open `CHZ-FO-CLI-PATH-LOCK`.
