The context pack now carries the P1.2 rolling summary (PLAN v16 P1.1 x P1.2, R-CTX-3). When `LLM_ROUTER_ROLLING_SUMMARY=1`, `context_pack.build_pack` reads the session's row from `rolling_summaries` into `ContextPack.summary`, so it reaches the model inside the `<conversation-summary>` layer. This happens only in `mode="pack"` (a full pack already carries the whole conversation) and only at the doors whose session id keys a summary: hook, agent and mcp (`SUMMARY_DOORS`). The same privacy gate as `recent` applies: `LLM_ROUTER_SESSION_CONTEXT=local` withholds it from API providers, and `off` withholds it everywhere. A summary is capped at `SUMMARY_MAX_TOKENS` (2,000) on whole lines, and a single longer line is cut. With the feature off (the default), the only cost is one environment-variable read; `sessions.db` is never created by a read, and any read error means no summary.
