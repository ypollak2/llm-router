Status line fast tick (`LLM_ROUTER_STATUSLINE=fast` / `both`): the guard now checks the interpreter the tick will actually run (the cached absolute one from `.statusline_python`, else `python3`) instead of always requiring `python3` on PATH, so a host with no `python3` on PATH but a usable cached interpreter still gets the fast line. The fallback test now asserts which interpreter ran and that a relative cached path is never used.
