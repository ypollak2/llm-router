LC-12g: local-only text jobs (`LLM_ROUTER_LOCAL_TEXT_JOBS` unset, D-277) no longer send the text through an HTTP proxy, and never switch to another model on overflow. (1) Proxy. LiteLLM 1.103.0 (`uv.lock`) honours `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` for `localhost` too when `NO_PROXY` is unset, on both its aiohttp (default) and httpx transports. Measured offline with a fake proxy and a fake Ollama on loopback: the `/api/generate` request, prompt included, went to the proxy. On the pass-only path `providers.call_llm` now gives that one Ollama call its own httpx client (`trust_env=False`, no redirects), closed after the call; no environment variable or LiteLLM global changes. LiteLLM's model-info lookup (`POST /api/show`, model name only, no text) still uses LiteLLM's shared client. (2) Overflow. With `LLM_ROUTER_PACK_OVERFLOW=1`, an input too large for the passed model could switch the call to a larger local model that has no pass and got no live check. On the pass-only path that switch is now refused before any model call: `llm_text_job` returns `fallback` ("the input does not fit the passed local model"), attempts are not counted, no local-attempt error row is written, and the refusal is counted in `text_job_fail_closed` as `CHZ-FC-PROVIDERS-TEXT-JOB-OVERFLOW-SWITCH`. (3) Review nits from #714: a non-loopback `OLLAMA_API_BASE` is refused with its own reason, "endpoint is not loopback (text would leave the machine)", instead of "ollama did not answer". `doctor` now flags an unreadable fail-closed store as alarming, as it already does for the fail-open and interception stores. A `/api/tags` row without a digest now clears the cached digest instead of keeping the old one under a fresh `cached_at`. A test runs the real live-check success path against a loopback `/api/tags` server. (4) Disclosed limits (docs/local-check-routing.md): the check-to-generate window is milliseconds and still open; a loopback endpoint that forwards elsewhere (`ssh -L 11434:gpu-box:11434`, a local reverse proxy) passes the check and sends the text off the machine, which is the user's own configuration. Evidence: `tests/test_lc12g.py`.
