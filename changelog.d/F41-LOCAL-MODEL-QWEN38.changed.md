F41 / F38: the router's local model is now `qwen3.8-uncensored:latest` (owner decision 2026-10-17). New `model_discovery.preferred_local_model()` resolves `LLM_ROUTER_OLLAMA_MODEL`, then qwen3.8-uncensored when installed, then the existing discovery order; the hardcoded `qwen3.5:latest` fallbacks in `hooks/auto-route.py` (hook version 62 to 63, both copies) and `zero_claude_edit.edit_model()` use it. The Ollama watchdog `gate()` no longer runs a 1-token `/api/generate` on the prompt path: it reads persisted state only and spawns a detached, rate-limited `python -m llm_router.ollama_watchdog --probe`, which generates only on the preferred model and only when it is already resident, so a probe never loads a model. Hung detection (`fail_n` failures flip, one success clears) is unchanged; a hang is now noticed one background round later. Cloud chains, tier policy and the promote gate are untouched.
