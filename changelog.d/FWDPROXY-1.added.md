Add `llm-router fwdproxy` (beta, opt-in, off by default): a loopback forward proxy plus the `claude-rc` launcher so Claude Code Remote Control, which needs `ANTHROPIC_BASE_URL=api.anthropic.com`, can still be routed through the router proxy. Name-constrained local CA (never in the keychain), blind tunnels for every other host, fail-open to the real API, `ca|install|uninstall|status` with launchd/systemd service and a rename-only rollback. An empty connection (the launcher's `nc -z` probe) is logged as mode `PROBE` instead of `ERR ? NotConnect405`. See docs/fwdproxy.md.
