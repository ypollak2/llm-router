`redo-label --owner`: every labelling screen now shows a one-line y/n/u definition above the key prompt (y = this message says the previous answer was wrong or incomplete and asks to fix, redo or retry it, or re-asks the same request; n = anything else). When a complete owner pass of at least 10 labels is all y or all n, the command prints a warning with the count and how to redo the pass before writing `owner_done.json`; the labels and the marker are recorded as given. Labels file format, judge mode, sampling and scoring are unchanged. Evidence: tests/test_redo_label.py::test_owner_screen_shows_the_label_definition, tests/test_redo_label.py::test_all_identical_owner_pass_warns_but_records_as_given, tests/test_redo_label.py::test_mixed_owner_pass_prints_no_warning.
