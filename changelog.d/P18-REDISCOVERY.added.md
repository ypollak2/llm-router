Map re-discovery (PLAN v16 P1.8 tasks 8 and 10). The resource map rebuilds when an env file, the Codex auth file, `usage.json` or `codex_quota.json` changes mtime, or when the signature of Ollama's `/api/tags` changes. The signature hashes the sorted `(name, digest, modified_at)` triples, so a re-pull under the same name is detected; the map's Ollama rows gain an additive `digest` key (schema stays 1). Diffs are appended to `map_changes.jsonl`, and the next UserPromptSubmit hook output carries one line such as `map: + qwen3.6 local`. The MCP server and the proxy poll every 30 s; with neither running, the hook starts one detached refresh (stat-only check, 60 s debounce). `auto-route.py` hook version 52. New state files: `map_watch.json`, `map_notice_cursor.json`, `map_changes.jsonl`, `map_refresh.lock`, `map_refresh.spawn`. Opt out with `LLM_ROUTER_MAP_REDISCOVERY=0`.
