Delegated Codex runs (`agent-route.py`, including its Phase-2 CLI path) now choose their sandbox from the session's directory, the hook payload's `cwd` (owner decision D-357, ruled "write in repo"). A session inside a git work tree gets `--sandbox workspace-write` with the network off (`sandbox_workspace_write.network_access=false`), and the work tree's top level is the only writable root and Codex's working directory. A session rooted at the home directory, outside any repository, or in a repository that sits at or above the home directory gets `--sandbox read-only` (network off as well), and a reply that reports blocked work is not delivered, so Claude's sub-agent does the task. A session rooted at `/` is not delegated (`codex_unsafe_cwd`). Before, every delegated run was read-only and most answers reported blocked work. The router chain and the MCP tools still pass no sandbox flag, and `danger-full-access` cannot be requested through `run_codex`. The Phase-2 path now has the blocked-answer gate the NS3 path had. `delegated` and `codex_blocked` ledger rows carry the `sandbox` the run had. `northstar` counts a `codex_blocked` row as a discarded attempt. Delegated runs now also pass `--ignore-rules` (no execpolicy rule, user or project, can run a command outside the sandbox with network: reproduced on the real binary, `docs/bugs/BIND-6.md`) and, in workspace-write, close `/tmp` and `$TMPDIR`; the child's `TMPDIR` is a per-run directory inside the work tree, ignored by git and removed after the run. The router chain and the MCP tools still pass neither flag. The writable root must also be the nearest directory with a `.git` entry at or above the session's, so a repository's own `core.worktree` cannot widen it to an ancestor (`docs/bugs/BIND-7.md`). The blocked-answer gate now catches the network and approval wording of a writable run, no longer flags a finding that mentions "connection refused" or "this session", and passes a reply that could not save its report file but carries the report (precision and recall before and after: `docs/bugs/BIND-2.md`). The `delegated` ledger row carries `answer_chars`, and the shadow verifier's marker is queued only after a writable run (a read-only run's `git diff HEAD` is the user's own work).
