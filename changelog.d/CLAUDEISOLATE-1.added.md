Claude CLI offload: optional isolation. With `llm_router_claude_offload_isolate` / `LLM_ROUTER_CLAUDE_OFFLOAD_ISOLATE` set true (default false: argv and cwd unchanged), the offload's `claude -p` adds `--setting-sources project,local --strict-mcp-config` and runs in an empty private directory (`<tmp>/llm-router-claude-offload-<uid>`, mode 0700; if that directory is not a real dir owned by this user or is group/world-writable, a warning is logged and the caller's cwd is kept). It no longer loads the user's settings or hooks (including llm-router's own), any MCP server, or the CLAUDE.md files of the caller's cwd, and file access relative to the caller's cwd is gone (tools stay on but operate in the empty directory). OKF/context injection stays scoped to the real project. The mode and the actual cwd are part of the resume key, so toggling never resumes a session created under the other mode.
