Claude CLI offload: optional isolation. With `llm_router_claude_offload_isolate` / `LLM_ROUTER_CLAUDE_OFFLOAD_ISOLATE` set true (default false, argv unchanged), the offload's `claude -p` adds `--setting-sources project,local --strict-mcp-config`, so it no longer loads the user's settings, hooks (including llm-router's own) or any MCP server, whose per-call-varying output defeats the prompt cache. Tools stay available. The mode is part of the resume key, so toggling it never resumes a session created under the other mode.
