The local routing verdict now runs in the hooks (`llm_router/door_verdict.py`), not only in the proxy shadow. With `LLM_ROUTER_LOCAL_CLASSIFIER=shadow`, `auto-route.py` logs one text-free row per routed prompt and `agent-route.py` one per routed Agent spawn in `door_verdicts.jsonl` (verdict, door, residency, latency, outcome, `tool_use_id`); nothing changes. With `on`, an opus verdict at p_max >= 0.6 (`LLM_ROUTER_DOOR_OPUS_MIN_CONF`) picks the `claude` door: the prompt hint is quieted, or the spawn makes no Codex attempt (unit `unsuitable`, `reason_code=verdict_claude`). Every other verdict, and no verdict, leaves the existing gates in charge: a verdict opens no door they keep shut. The hook waits through a cold model load (`LLM_ROUTER_DOOR_VERDICT_BUDGET_MS`, default 8,000) and a breaker opens only after two failures in a row. `scripts/door_verdict_report.py` reads the ledger; `scripts/door_verdict_check.py` is a real check capped at 30 model calls. Measured 2026-11-04 on this machine at load average 6.3-6.8 (n=5 prompts after an eviction, n=4 warm): 5 of 5 verdicts, first call 5,824 ms, warm p50 351 ms and p95 380 ms; the proxy path answered 0 of 3 after an eviction (cold, timeout, timeout).
