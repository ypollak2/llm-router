The auto-route hook (v62) no longer reads and parses the whole Claude Code transcript twice per prompt: it reads a 256 KB tail window (doubling only when the tail holds too few turns) and parses it once, shared by the assistant-turn persist, the draft-usage audit and the draft history, so the session-store content is unchanged. `routing_report.draft_acceptance` (every 10th prompt) counts from a sidecar offset instead of scanning the whole `auto-route-debug.log`, and the log is now rotated at 8 MB keeping 3 backups. Policy YAML loads with libyaml's `CSafeLoader` when present, `task_availability.resolve` reads the active policy once, and `session_store` / the hook no longer import tiktoken or `okf` on the per-prompt path. Every auto-route latency row now carries `router_added_ms` (elapsed minus model phases, as `agent-route`) and new phases `engine`, `availability`, `mini_summary`, `trend`.
