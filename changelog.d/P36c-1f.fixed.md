`redo-sample --include-untagged` now resolves sessions through the proxy ledger's session stamps before counting them untagged. The census reports the backfill sidecar state (`present` / `missing` / `unreadable`, with a warning when unreadable) and untagged counts by cause in three facets (tag: `no_tag_file` / `corrupt_tag`; ledger: `no_ledger_stamp` / `ledger_conflict` / `ledger_not_read`; sidecar: `sidecar_missing` / `sidecar_unreadable` / `sidecar_no_entry` / `sidecar_unknown`). Exclusion-file lines that are not 16 lowercase hex characters refuse with exit 2 and a count only, for the shipped and the local file; a group- or world-readable local exclusion file gets a warning. `redo-score` reports per-kind precision/recall only for runs frozen with `--include-untagged`, and per-kind recall is not estimable for a concentrated draw. Frozen and draw-row weights are labelled combined (`weights_combined`, `weight_N_h_combined`, `n_h_combined`).
