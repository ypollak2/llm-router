- Proxy: the classifier SHADOW lane (`proxy/cls_embed_shadow.py`, PR-4), on only with `LLM_ROUTER_CLS_EMBED=shadow` (default off: nothing runs, rows and goldens unchanged). After the rules decide a human turn in local-agent mode, one detached task embeds the assembled prompt on the small Ollama server and appends a text-free record (`cls_emb_*`, `session_id`, `text_sha`, `msg_id`, `pop`, `step_class`, `rules_decision`, `late`) to `cls_embed_shadow.jsonl`. It never changes a routing decision and the request never waits for it: its own 4-thread executor (not the default one), `asyncio.wait_for` at the 250 ms budget (a slow embed is recorded as an abstain, `timeout`, `late: true`), a pending cap of 4 that frees a slot only when the thread ends (overflow is recorded as `queue_full`, never queued), one embed per human turn per `(session_id, text_sha)` per 10 minutes (the key is set only once the task is accepted), the secret scan and every record write run on pool threads (nothing but enum checks on the event loop), `cls_embed_shadow.jsonl` rotates to `.1` at 50 MB, shutdown gives pending tasks 1 s. Side calls, permission checks (`not_eligible`), `claude_marker` rows, continuations and secret-holding prompts are never embedded. Ledger rows get no new field.
