P3.6-c PR2: `llm-router redo-score --run ID` scores frozen text-free validation labels with owner precedence, source agreement, Wilson precision, stratified recall and seeded session-cluster bootstrap intervals. It checks detector/manifest hashes, refuses invalid labels and reused runs, records a private single-use marker before results, and supports a write-free `--dry-score`. The precision gate requires precision >=0.80 and TP>=15, becomes inconclusive when unclear-label sensitivity changes the outcome, and is void above 5% lost labels; concentrated capped draws report precision but no recall estimate. Evidence is limited to synthetic fixtures in `tests/test_redo_score.py`, not an owner validation run.
