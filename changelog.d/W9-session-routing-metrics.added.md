Status line, two per-session numbers computed by the detached refresher (owner goal 2026-11-04: more than 15% of LLM calls routed to a non-Claude or local model; Sonnet and Haiku do not count): `routed X% (n/N calls, session)` and `local OK Y% (a/b, session)`; `local OK n/a (0 attempts, session)` when the session made no local attempt, never 0%. Where it shows: default layout, a third row under the snapshot row (also in `LLM_ROUTER_STATUSLINE=both`, where the full part prints it and the tick prints none, so it never doubles); `LLM_ROUTER_STATUSLINE=fast`, a row under the tick line once the session has a snapshot. Units: a call is one model API response, an attempt is one try of one model by the router's chain, a run is one delegated `codex exec` (many calls). N is the unique `message.id` over the session's main, `subagents/agent-*.jsonl` and `subagents/workflows/wf_*/agent-*.jsonl` transcripts plus the non-Claude calls. n is each model response of a DELEGATED Codex run (read from the rollout, Codex's own sub-agent threads included; no rollout counts as one and the row says `1 Codex run est.`), each router attempt a non-Claude provider answered and the router accepted (`execution_events.attempt_completed`, joined to the session through the route's `correlation_id`/`trace_id`; an MCP `llm_*` call logged under `unknown:mcp` is joined by the transcript's `tool_use` id), and each Claude Code message the proxy served from a non-Claude model. A `codex_blocked` or `codex_failed` run is discarded work (`northstar._CODEX_ATTEMPT_OUTCOMES`: Claude re-runs it) and is never in n. b is the session's local attempts, every outcome (`attempt_completed`, `attempt_failed`, `attempt_rejected`), so a first-choice model that is not installed and is rescued by the next chain entry is a failed attempt; a is those used: completed and not rejected afterwards by a text job's acceptance check (`text_job_local_attempts.jsonl`). `routing_decisions.success` is not used (it is "the response is usable" for the whole call). Definitions: `src/llm_router/session_routing.py`; tests: `tests/test_session_routing.py`.
