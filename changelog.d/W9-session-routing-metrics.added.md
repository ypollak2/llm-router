Status line, two per-session numbers computed by the detached refresher (owner goal 2026-11-04: more than 15% of LLM calls routed to a non-Claude or local model; Sonnet and Haiku do not count): `routed X% (n/N calls, session)` and `local OK Y% (a/b, session)`, printed as a row under the snapshot row in the default layout and under the tick line in `LLM_ROUTER_STATUSLINE=fast`/`both`; `local OK n/a (0 attempts, session)` when the session made no local attempt, never 0%. N is the unique `message.id` over the session's main, `subagents/agent-*.jsonl` and `subagents/workflows/wf_*/agent-*.jsonl` transcripts plus the non-Claude calls; n is each model response of a Codex run agent-route delegated for the session (read from the run's rollout, sub-agent threads included; a run with no rollout counts as one and the row says so), each router call a non-Claude provider answered (`routing_decisions.success = 1`; an MCP `llm_*` call is joined to its row by the transcript's `tool_use` id), and each Claude Code message the proxy served from a non-Claude model; b is the session's local-provider rows (failures included, cache hits and cancelled calls excluded) and a those that succeeded. Definitions and exclusions: `src/llm_router/session_routing.py`; tests: `tests/test_session_routing.py`.
