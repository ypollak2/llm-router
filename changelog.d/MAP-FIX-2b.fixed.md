MAP-FIX-2b: updates to `cli_path.json` now run under an exclusive lock (`cli_path.json.lock` in the state dir), so two processes learning different CLI dirs at the same moment no longer lose one of the entries. A CLI found through a relative PATH entry is still used by the process that found it, but its dir is no longer written to the shared file, because a relative dir means something different in every process's working directory.
