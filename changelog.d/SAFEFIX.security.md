The local agent lanes are now allowlist-only (owner decision D-322). `llm_act`, `llm_local_task`'s `run_command` and the toolkit all go through `write_policy.check_action`, which now runs only the programs on one allowlist (`write_policy.allowed_programs()`): read and inspect tools, the in-root writers whose targets the tripwire already reads, read-only `git` plus `git add`/`mv`/non-recursive `rm`, project scripts, and the test and build tools (`pytest`, `go build|test|run`, `cargo build|test|run`, `npm test|run`, `ruff`). Any other program is refused, so commands such as `crontab -r`, `diskutil eraseDisk`, `unlink ~/.zshrc`, `tar -C /` and `git read-tree --reset -u` no longer run on `llm_act`. For allowed programs the policy reads their own flags: output and working paths (`sort -o`, `tree -o`, `git --output`, `go build -o`, `pytest --basetemp`, `git -C`, a script path) must resolve inside the project root, and flags that delete or run a command are refused (`find -delete/-exec`, `rg --pre`, `git -c core.pager/alias/core.fsmonitor/diff.external`, `git grep --open-files-in-pager`, `go -exec`, `cargo --config`, an existing `pytest --basetemp` directory). `python -m` is limited to `pytest`, `unittest`, `py_compile`, `compileall`, `json.tool` and `ruff`; `timeit`, `tarfile`, `zipfile`, `runpy` and the rest are refused. A command prefix may set only harmless variables (`PYTHONPATH`, `NO_COLOR`, ...). `LLM_ROUTER_AGENT_COMMANDS=all` still lifts `llm_local_task`'s narrower inspection list but no longer lifts this allowlist. Some local tasks that used to run are now refused, for example `make`, `bash script.sh`, `git fetch` and `go mod tidy`. Every command of the UN-15 known-gaps table (PR #778) moved to SECURITY.md's refused tables, which the doc-driven test drives through the real lanes, and SECURITY.md no longer says the contract is unmet. It now names the accepted residual instead: the lanes still run the project's own code (scripts, test runners, `go run`, `cargo run`, `npm run`), and on `llm_act` that can be a file the model has just written.
