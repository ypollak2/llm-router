UN-04b: a prompt holding a high-precision secret (API key, token, private key) is no longer sent to a cloud CLI or API through three doors that skipped the secret door. The `llm_codex` and `llm_gemini` MCP tools now refuse it, naming the category and never the value, as `route_and_call` does when it has no local model. The subagent hook (`hooks/agent-route.py`, direct execution) now keeps such a prompt on loopback Ollama models and runs nothing when none is available, so the real subagent spawn proceeds. The `cloud:` prefix overrides in all three, logged as a count only. Evidence: `tests/test_un04b_secret_door_cli_and_agent_route.py`.
