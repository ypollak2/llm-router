LC-6 (`llm-router local-check`): new CLI that measures the user's own local model on the bundled public benchmark. `local-check [run]` discovers a runtime (`--endpoint`, loopback only unless `--allow-remote`), shows a plan screen (model + digest, hardware, items in scope, time, judge route, cost and cap, consent), then runs through `local_check.session`; `--dry-run` makes zero model calls, `--no-judge` can only record a FAIL, `--yes` is required without a terminal, `--profile quick` limits diffs to 12k characters, `--fresh` discards the open run (a strike). Refuses below 50 items in scope with `num_ctx` advice. Judge route (D-260): the user's Anthropic API key, else the `claude` CLI (subscription; warn above 80 %, refuse above 95 % of the plan unless `--force`), else `--no-judge` only; `ANTHROPIC_BASE_URL` pointing at llm-router's own proxy (sentinel port, `LLM_ROUTER_PROXY_PORT`, defaults) makes the judge go direct to api.anthropic.com, any other custom base URL refuses the API route (D-264). `status` and `explain` (per-rule failure histogram with public item ids, no item text). Probe, run-start, mismatch, budget and judge-setup errors and Ctrl-C map to distinct exit codes with clear messages (docs/local-check.md). LC-5b fixes in `local_check.session`: an unexpected exception or Ctrl-C after the local arm leaves a reservation without a strike; a missing or empty run directory of an open reservation is a discard strike; the 7-day expiry lapses without a strike (documented); removed the dead `inconclusive` branch in `text_job_lines`. Routing activation is not part of this change; the verdict screen says so. Evidence: `tests/test_lc6_cli.py` (fake runtime, fake judge, no network).
