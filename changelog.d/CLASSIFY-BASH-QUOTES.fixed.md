Proxy tool classifier: `classify_bash` now splits a Bash command on `|`, `;`, `&&`, `||` and newline, and detects redirects (`>`), only outside quotes and backslash escapes. A read-only command such as `rg "x|y" src` or `grep ">" f` was classed `exec` and is now `technical_op`. An unbalanced quote or trailing backslash still classes as `exec`; the read-only allow-lists are unchanged.
